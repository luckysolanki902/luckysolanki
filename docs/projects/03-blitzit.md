# Blitzit — AI-native task product

> **Role:** Core Backend Developer & AI Engineer
>
> **Timeline:** November 2025 → Present
>
> **Status:** Active

## Public summary

Blitzit is an AI-native task product. Lucky builds core backend systems that support product actions, integrations, background work, sync, and AI-tool interactions.

## Work I can discuss

- TypeScript and Fastify backend services with MongoDB, Redis, and BullMQ.
- Integration foundations for external products, including OAuth flows, provider webhooks, retries, scheduling, and bidirectional-sync concerns.
- MCP-based systems that expose product capabilities to AI models and agents.
- A reversible change journal for task actions, designed so a later user edit is not overwritten by an older reversal.
- Reliability work around token refresh, billing-entitlement handling, queues, and recovery paths.

## Positioning

This is the primary employment proof for an **AI Engineer / backend systems / agent infrastructure** profile. It demonstrates backend ownership, integrations, asynchronous systems, and practical agent-tool design.

## Detail boundary

Blitzit is team work. This case study intentionally avoids private repository links, internal line counts, unverified benchmark claims, customer data, and a historical MCP-tool count that may no longer be current. It also does not imply sole ownership of shared systems.
